**Descrição:**\
Sistema de Gestão para Kartódromo, uma solução criada para otimizar os processos operacionais e a divulgação comercial do estabelecimento. A pesquisa fundamenta-se na necessidade de modernizar a gestão de corridas, o cadastro de clientes, o controle de funcionários e a rotina diária de pistas de automobilismo recreativo, integrando um software local em VB.NET com simulação de telemetria via Arduino para controle de sinalização e monitoramento de pista a uma plataforma web voltada a agendamentos online. O ecossistema combina uma API em Node.js com Express e Prisma ORM, conectada a um banco de dados PostgreSQL hospedado no Render; um front-end em HTML, CSS, JavaScript, Bootstrap e jQuery, hospedado no GitHub Pages; e uma aplicação desktop de retaguarda desenvolvida em VB.NET, integrada a sensores e atuadores simulados via Arduino por meio de comunicação serial. A metodologia adotada tem caráter aplicado, exploratório e qualitativo, estruturada a partir da engenharia de software com foco na implementação de soluções web responsivas e na aplicação de testes de qualidade. Os procedimentos de análise contaram com testes unitários, de integração, de desempenho e de segurança, além de auditorias de acessibilidade. Como resultados, o sistema demonstrou eficácia na automação das rotinas operacionais, reduzindo a carga de trabalho manual da equipe e aprimorando a experiência do cliente no agendamento de baterias. Conclui-se que a solução atende aos requisitos funcionais e não funcionais estabelecidos, alinhando-se aos Objetivos de Desenvolvimento Sustentável (ODS) 8 e 9.\
